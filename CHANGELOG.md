# Changelog

## 20260418.7 - 2026-04-20

- Initial public release of the Codex Desktop 3P wrapper package.
- Added `install-codex-desktop-3p` for machines that already have third-party provider config and API credentials.
- Added `install-codex-desktop-3p-public` for shareable setup with placeholder `THIRDPARTY_BASE_URL` and `THIRDPARTY_API_KEY`.
- Added wrapper templates for the managed 3P CLI, desktop launchers, health checks, desktop-home sync, and cloned app preparation.
- Clarified README installation guidance for when to use the standard installer versus the public installer.
